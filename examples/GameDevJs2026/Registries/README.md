# Registries

Game content definitions: items, buildings, recipes, and the plain-data inventory container used throughout gameplay.

- `inventory.h` / `.cpp` — `Inventory` stack container with insert/remove/query
- `itemregistry.h` / `.cpp` — `ItemDef`/`ItemStack`/`ItemRegistry` + default item table
- `buildingregistry.h` / `.cpp` — `BuildingDef`/`BuildingRegistry` + default toolbar entries
- `reciperegistry.h` / `.cpp` — `Recipe`/`RecipeRegistry` + default furnace/assembler/hand-craft recipes
